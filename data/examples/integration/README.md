# Synthetic integration examples

All people, grades, source links, primary-instructor claims, ratings, and review evidence in this directory are invented. `data_kind` is `development_fixture`. The zero-valued grade and null-valued grade deliberately demonstrate distinct states. Synthetic primary designation is explicit rather than inferred from instructor order.

`python -m scripts.preview_integration` assembles these files with synthetic schedule/history fixtures into ignored `data/previews/`. Production publication rejects them. See the three teammate tasks for real output requirements.
