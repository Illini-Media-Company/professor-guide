## RMP coverage checkpoint

`python3 -m scripts.import_faculty --reuse-sources` adds NetID-backed identities from the saved official campus faculty rollup and Grainger faculty roster independently of GPA availability. It preserves existing IDs/ratings and creates no course or grade links. `faculty-directory-review.json` records the source snapshots, additions, and any unresolved profile-URI/NetID reconciliation. Individually verified teaching additions are documented in `teaching-identity-reviews.json`. These directory-only identities remain protected when the GPA-focused identity export is rebuilt.

`python3 -m scripts.review_rmp` audits the current identified instructor set against the anonymous public RMP UIUC search directory. The identity set is fixed within each run; unresolved schedule-name entries are not rating candidates. It retrieves the site's public aggregate/course fields through its GraphQL endpoint, follows all result pages, checks school identity, and records duplicate result IDs. Requests use a one-second interval and stop on access denial; no login, individual review text, or account data is collected.

Each instructor gets exactly one outcome in `rmp-identities.json` and `rmp-review.csv`: `verified_match`, `ambiguous_candidates`, `no_matching_profile_found`, or `lookup_unavailable`. Matching requires compatible full names, UIUC, and official unit or previously verified course context. `config/rmp-review.json` lists explicit department-label equivalents; they never establish name identity. Nicknames, shortened surnames, multiple supported profiles, and shared profile ownership remain unverified. A no-match outcome is limited to the results returned by this run, not proof that no profile exists. Directory duplicates and limitations are documented in the [report](../../docs/rmp-coverage.md).

Add `--reuse-sources` to replay cached aggregate data in ignored `.cache/rmp-review` without requests. Add `--apply` to export accepted numerical summaries to the existing instructor records; this preserves the instructor set, rebuilds this batch's prior ratings, and refuses to apply incomplete pagination. Independent ratings require explicit reconciliation. The public publication and Pages workflow are separate and remain paused for this checkpoint. Every accepted summary records matching evidence, raw/normalized metrics in the ledger, source timestamps, and retrieval hashes.
